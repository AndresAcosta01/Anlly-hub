¿Cómo agregar a alguien?

  1. Entra a tu proyecto en supabase.com → Authentication → Users.
  2. Pulsa Add user → Create new user, escribe el correo y una contraseña temporal, y marca Auto Confirm User.
  3. Comparte la contraseña con la persona. Aparecerá aquí como supervisor.
  4. Si debe ver Nómina y Horarios, cámbiale el rol a admin.
